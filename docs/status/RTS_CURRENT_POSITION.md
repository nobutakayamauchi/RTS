## HARD-005の結果

12件の合成敵対入力を用いた。

| 処理 | 件数 | 意味 |
|---|---:|---|
| STOP | 4 | 認証情報・鍵素材を検知し、レポート生成を停止 |
| EXCLUDE | 2 | 高リスク識別子を処理対象から除外 |
| MASK | 5 | メール、電話、氏名・住所、IP等を型付きマスキング |
| ALLOW | 1 | 保護対象を含まない公開情報のみ通過 |

初回は2件を取りこぼした。

- 空白区切りの `client secret`
- `[at]` / `[dot]` 表記のメール

初回記録を残したまま2修正を行い、再試験では12件すべて成功した。

```text
最終失敗                 0
マスキング後の残留検出   0
保護対象の生データ保存   0
```
