## 個別連絡文

英語の連絡文は、まず1枚の範囲説明を受け取る意思があるかだけを尋ねる。

- 公開Repo 1件・固定コミット1件
- 1回限定・無償
- 非公開コード、認証情報、顧客データを要求しない
- Repoアクセス、コード変更、投稿権限を要求しない
- 支払い・営業・商用約束を含まない
- 返信は興味表示のみで同意ではない
- 分析開始には別の範囲説明と書面同意が必要
- 成果物は別途承認がない限り非公開
- 拒否・撤回はいつでも可能

文面は完成しているが、送信状態は `NOT_SENT`、送信回数は0である。

## 送信前チェックと返信処理

全18項目を必須とし、部分合格を認めない。現工程では送信上限0件、追撃上限0件である。

```text
肯定的な興味表示   人間審査後に別の範囲説明・同意票を提示可能
拒否               即終了
曖昧               受付・分析せず終了
無反応             追撃せず14日で終了
秘密情報の混入     即停止、生データを保持せず人間へ上げる
```

どの返信も自動的な同意、顧客受付、パイロット開始にはならない。
