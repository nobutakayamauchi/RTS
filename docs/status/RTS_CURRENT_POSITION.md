## Disclosure Policy

公開候補に含められるもの：

- 承認済みのRTS／Proof Engineの説明
- 大まかな現在地と非目標
- 既に公開済みの証拠と承認済みP3成果
- 人間とAIツールの役割分離
- 限界、保留、未証明事項
- 私的事情を除いたCASE-001の開発透明性
- 非稼働の問い合わせ入口プレースホルダー

含めないもの：

- 私信本文、スクリーンショット、Discord固有ID
- 宛先の返信状況や待機日時
- 秘密情報、非公開Repo、顧客・プロバイダーデータ
- 健康、家族、雇用紛争、法律、金融、位置情報等のセンシティブ情報
- 生の会話ログや入力ミスを含む非公開指示
- 未証明の本番性、顧客価値、売上、万能性
- 人物ランキング、価格・契約・納品の約束

新規公開ページ、README導線、連絡入口、SNS、別媒体への掲載は、それぞれ別の人間承認を必要とする。
