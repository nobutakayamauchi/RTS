# FRZ-000018 Model Transition Intelligence + Architecture Contract Diff v1

Implement a provider-neutral, repository-local transition-intelligence layer over immutable old/new official-document evidence bundles.

The layer must:
- validate exact source provenance and content digests;
- compare normalized external contract claims across generations;
- classify transition severity as S0/S1/S2/S3 without claiming hidden model architecture;
- keep documentation claims as hypotheses until F/G observation confirms them;
- derive bounded F probe dimensions and G campaign breadth;
- downgrade/quarantine reuse assumptions on severe external contract shifts without deleting historical profiles;
- remain read-only/non-authorizing with no provider calls, crawler, runtime mutation, or promotion authority.

DA death conditions include marketing-only escalation, docs-claim-as-observed-behavior, hidden architecture inference, conflicting-doc certainty, missing provenance acceptance, unbounded probes, and automatic runtime/profile mutation.
