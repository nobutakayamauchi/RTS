## Legal / privacy / authority lessons that survive

1. **Do not expose unnecessary raw wording.** Where auditability can be preserved with normalized intent plus one-way fingerprint linkage, the normalized representation is preferred.
2. **Do not publish secrets or personal/sensitive data.** Public evidence should use bounded references rather than raw private payloads.
3. **Fail closed on external action.** Recommendation, analysis, or review evidence does not itself authorize contact, publication, repo mutation, contracting, delivery, monitoring, or other external action.
4. **Human/project authority remains explicit and scope-limited.** Permission for one surface does not imply permission for another.
5. **Unknown stays UNKNOWN.** Lack of evidence may not be silently promoted to verified fact.

## Thin RTS target

The successor earns the name RTS only if it can demonstrate, without reviving a custom kernel, the following continuous reconstructable chain:

`INTENT / REQUIREMENT`
→ `AUTHORITY + CONSTRAINTS`
→ `ACTION / EXECUTION REFERENCE`
→ `OBSERVED RUNTIME / MATERIAL IDENTITY WHEN RELEVANT`
→ `OUTCOME EVIDENCE`
→ `FAILURE / RECOVERY / SUCCESS CLASSIFICATION`
→ `LEARNING PROPOSAL`
→ `REGRESSION / COUNTER-EVIDENCE`
→ `SEPARATE PROMOTION AUTHORITY`
→ `CHANGED STATE`
→ `RE-ENTRY / NEXT DECISION`

Every link may be externally owned. Thin RTS only needs enough structure to bind and reconstruct the chain.
