## What this stage does

This stage defines and reviews exactly one later customer-pilot cycle. It does not select or contact a participant and does not run intake or a pilot.

The planned pilot is bounded to:

- one consenting solo developer or solo founder;
- one public repository;
- one fixed commit and merged-PR evidence boundary;
- one operator-assisted report cycle;
- no payment or commercial consideration;
- no source or target repository writes;
- no automatic publication or delivery.

## Eligibility and intake

A later execution review may consider a participant only when all of the following can be established:

1. the participant owns, administers, or is documented as authorized for the public repository;
2. explicit written consent is obtained before analysis;
3. one bounded analysis objective is recorded;
4. privacy and credential preflight passes;
5. no repository modification is requested;
6. no pricing, outreach, contract, delivery, or publication expectation is implied.

No real participant has been selected. No contact or intake has occurred.

## Planned data boundary

Allowed:

- exact public repository commit;
- merged pull-request metadata inside the frozen boundary;
- public repository documentation;
- a bounded objective with no protected data;
- synthetic validation fixtures.

Prohibited:

- private repositories or private code;
- credentials, tokens, keys, passwords, or secrets;
- customer or end-user payloads;
- HR, medical, financial, legal, or government-identifier data;
- confidential third-party data;
- unbounded mailbox, chat, drive, or ticket exports;
- unknown-origin copied material.

## Planned success threshold

A pilot can later pass only when all eight required success criteria pass and no failure condition remains open.

The threshold includes:

- exact source and consent validity;
- deterministic two-build reconstruction;
- evidence-bound verified claims and retained withheld claims;
- zero privacy, credential, or unapproved-action incident;
- at least five of six comprehension checks correct with no critical confusion;
- usefulness rating of at least three of five and one evidence-supported next action;
- complete operating metrics;
- an explicit human accept, revise, or stop decision.

Partial success is prohibited.

## Incident response

Any secret, private source, prohibited data, source escape, unsupported material claim, or authority widening stops the planned pilot.

The incident record may retain fingerprints, detector class, time, scope, and the human decision. It must not copy prohibited raw payloads. Resume requires a new explicit human authorization.
