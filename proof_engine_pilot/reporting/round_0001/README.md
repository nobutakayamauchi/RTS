# Evidence-Backed Achievement Discovery Report Template v1

This internal template turns reviewed repository evidence into a repeatable report structure.

## Required sections

1. Executive summary
2. Repository scope
3. Methodology
4. Evidence inventory
5. Effective achievement records
6. Human and AI contribution map
7. Withheld or unsupported claims
8. Limitations
9. Human review decision

The demonstration pack contains one report for each validation repository and covers all sixteen effective candidates plus all five withheld claims.

## Commands

```bash
python -m proof_engine_pilot.report_template_cli verify
python -m proof_engine_pilot.report_template_cli summary
python -m proof_engine_pilot.report_template_cli generate
python -m proof_engine_pilot.report_template_cli render-markdown
python -m proof_engine_pilot.report_template_cli review-template
```

The template does not price, sell, send, deliver, publish, approve, or modify a target repository. Current state: `HUMAN_REPORT_TEMPLATE_REVIEW_REQUIRED / NOT_PUBLISHED / NOT_DELIVERED`.
